MATCH SESSION SYSTEM

Match Session Management
Handles multi-round match progression through playlist.

Scripts
- MatchSessionManager

Responsibilities
- Maintain playlist of rounds (scene + game mode)
- Track current round index
- Initialize player scores
- Load next round from playlist
- End match when playlist completes

Playlist System
- Configurable list of PlaylistEntry (sceneName + gameMode)
- Server-authoritative round progression
- Automatic scene loading via NetworkManager.SceneManager

Round Progression
- StartMatch() initializes scores and loads first round
- LoadNextRound() advances to next playlist entry
- EndMatch() called when playlist exhausted

Integration
- LobbyUI calls MatchSessionManager.StartMatch()
- RoundEndTrigger calls MatchSessionManager.LoadNextRound()
- RunnerRoundTracker can trigger round end when all runners fall

SPAWN POINT SYSTEM

Spawn Point Component
Location-based spawn point system with type and index.

Scripts
- SpawnPoint
- SpawnPointType (enum)

SpawnPoint Properties
- type: SpawnPointType (Generic, RunnerStart, SabotagerStart, RaceStart, Checkpoint)
- index: int (for ordering multiple spawns of same type)

Spawn Point Assignment
- GameModeManager finds all SpawnPoints on scene load
- RunnerSabotagerGameManager assigns by role and index
- Players of same role assigned to spawns in order
- Falls back to Generic spawn if role-specific not found

Fixed Behavior
- SpawnPoints automatically discovered via FindObjectsByType
- Proper role-based assignment with index cycling
- Respawn points assigned from initial spawn location

ROUND SYSTEM

Round End Triggers
Multiple ways to end a round and progress to next.

Scripts
- RoundEndTrigger (manual trigger)
- RunnerRoundTracker (automatic when all runners fall)

Round End Flow
- Trigger calls MatchSessionManager.LoadNextRound()
- MatchSessionManager loads next playlist entry
- New scene loads with appropriate GameModeManager
