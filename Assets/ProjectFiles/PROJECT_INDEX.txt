PROJECT_INDEX
Multiplayer Minigame Playlist Platform
Unity 6 / URP

END GOAL
A multiplayer minigame collection platform (similar to GTA V's Playlist system) where:
- Host selects game modes from available minigames to create custom playlists
- Each game mode has its own scene
- Each game mode can have multiple turns/matches within a round
- Players progress through the playlist, accumulating scores across all minigames
- RunnerSabotager is one of many game modes in the collection

MATCH SESSION SYSTEM

Match Session Management
Handles multi-round match progression through custom minigame playlists.

Scripts
- MatchSessionManager

Responsibilities
- Maintain playlist of minigames (scene + game mode)
- Track current round index
- Initialize and persist player scores across all minigames
- Load next minigame from playlist
- End match when playlist completes
- Support multiple turns/matches per game mode

Playlist System
- Host-selectable list of PlaylistEntry (sceneName + gameMode)
- Each entry represents one minigame in the playlist
- Server-authoritative round progression
- Automatic scene loading via NetworkManager.SceneManager
- Scores accumulate across all minigames in playlist

Playlist Customization (Planned)
- Host can cherry-pick game modes in lobby
- Available game modes: RunnerSabotager, Race, Minigame, Puzzle, etc.
- Each game mode can be added multiple times to playlist
- Playlist persists for entire match session

Round Progression
- StartMatch() initializes scores and loads first minigame
- LoadNextRound() advances to next playlist entry
- Each game mode can have multiple turns/matches before advancing
- EndMatch() called when playlist exhausted

Integration
- LobbyUI calls MatchSessionManager.StartMatch()
- RoundEndTrigger calls MatchSessionManager.LoadNextRound()
- GameModeManagers can trigger round end when conditions met

GAMEPLAY ROLES

Role system is game-mode specific. RunnerSabotager uses:

Runner
- Moves on elevated obstacle course
- Respawns on fall

Sabotager
- Moves on ground
- Uses abilities to disrupt runners

Supported player counts (RunnerSabotager)
- Up to 4 Runners
- Up to 4 Sabotagers

Note: Other game modes may use different role systems or no roles at all.


GAME MODE SYSTEM

Game Mode Managers
Base class for all game mode implementations.

Scripts
- GameModeManager (abstract base)
- RunnerSabotagerGameManager
- RaceGameManager

GameModeManager Responsibilities
- Find all SpawnPoint components in scene
- Spawn players for connected clients
- Provide spawn point selection logic

Game Mode Types
- RunnerSabotager (asymmetrical obstacle course)
- Race (competitive racing)
- Minigame (various small games)
- Puzzle (puzzle-solving challenges)
- Additional game modes can be added

Architecture
- Each game mode has its own scene
- Each game mode has its own GameModeManager implementation
- Game modes are independent and can be mixed in playlists
- Each game mode can support multiple turns/matches per round

Scripts
- GameModeType (enum)


SPAWN POINT SYSTEM

Spawn Point Component
Location-based spawn point system with type and index.

Scripts
- SpawnPoint
- SpawnPointType (enum)

SpawnPoint Properties
- type: SpawnPointType (Generic, RunnerStart, SabotagerStart, RaceStart, Checkpoint)
- index: int (for ordering multiple spawns of same type)

Spawn Point Assignment
- GameModeManager finds all SpawnPoints on scene load
- RunnerSabotagerGameManager assigns by role and index
- Players of same role assigned to spawns in order
- Falls back to Generic spawn if role-specific not found

Fixed Behavior
- SpawnPoints automatically discovered via FindObjectsByType
- Proper role-based assignment with index cycling
- Respawn points assigned from initial spawn location

ROUND SYSTEM

Round End Triggers
Multiple ways to end a round and progress to next.

Scripts
- RoundEndTrigger (manual trigger)
- RunnerRoundTracker (automatic when all runners fall)

Round End Flow
- Trigger calls MatchSessionManager.LoadNextRound()
- MatchSessionManager loads next playlist entry
- New scene loads with appropriate GameModeManager
